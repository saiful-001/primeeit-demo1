# 🍯 খাঁটি মধু ও প্রিমিয়াম হানি নাট ল্যান্ডিং পেজ (Landing Page)

একটি সম্পূর্ণ প্রফেশনাল, আল্ট্রা-ফাস্ট এবং কনভার্শন-অপ্টিমাইজড ল্যান্ডিং পেজ—যেখানে কাস্টমাররা **খাঁটি মধু** এবং **প্রিমিয়াম হানি নাট** একত্রে বা আলাদাভাবে এক বা একাধিক (Multiple Products) সিলেক্ট করে সরাসরি অর্ডার করতে পারবেন।

> 📖 **সহজ নির্দেশিকা:** কোন জায়গায় কোন লিংক দিতে হবে এবং কীভাবে কনফিগার করতে হবে তা সহজে জানতে আমাদের [SETUP-GUIDE.md](SETUP-GUIDE.md) ফাইলটি দেখুন।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **একত্রে মধু ও হানি নাট বিক্রয়:**
   - খাঁটি মধু (৫০০ গ্রাম ও ১ কেজি)
   - প্রিমিয়াম হানি নাট (৫০০ গ্রাম ও ১ কেজি)
   - মেগা কম্বো প্যাক (মধু + হানি নাট)
2. **মাল্টিপল প্রোডাক্ট চেকআউট (Interactive Cart):**
   - কাস্টমার একসাথে যত খুশি পণ্য সিলেক্ট করতে পারেন।
   - প্রতি আইটেমের সাথে নিজস্ব কোয়ান্টিটি কাউন্টার (+ / -)।
   - রিয়েল-টাইমে সাব-টোটাল, ডিসকাউন্ট, ডেলিভারি চার্জ ও সর্বমোট হিসাব।
3. **অল-ইন-ওয়ান কনফিগারেশন (`js/config.js`):**
   - ১টি ফাইল থেকেই গুগল শিট, ফেসবুক পিক্সেল, পণ্যের দাম ও ওয়েবসাইটের সব বাটনের লেখা পরিবর্তন করা যায়।
4. **ASCHII SOLUTION প্রফেশনাল CRM গুগল শিট:**
   - রেফারেন্স ডিজাইন অনুযায়ী উপরে লাইভ KPI কার্ড ও ব্র্যান্ডিং ব্যানার।
   - পাশাপাশি ২টি সেকশন: **বাম পাশে সম্পূর্ণ অর্ডার তথ্য** এবং **ডান পাশে সম্পূর্ণ ফেসবুক পিক্সেল ও ট্র্যাকিং তথ্য**।
5. **ভিজিটর সেশন ও ফেসবুক পিক্সেল ট্র্যাকিং:**
   - ভিজিটর কতক্ষণ পেজে ছিল, কোন পণ্য কার্টে এনেছে এবং ফেসবুক অ্যাডসের `fbclid`, `_fbp`, `_fbc` সহ সম্পূর্ণ ডাটা স্বয়ংক্রিয়ভাবে জমা হয়।
6. **ফ্রড ও স্প্যাম প্রটেকশন (Fraud Guard):**
   - একই ব্যক্তি বা বট একই নাম্বার দিয়ে বারবার অর্ডার পাঠিয়ে শিট জ্যাম করা রোধ করতে ১৫ মিনিটের কুলডাউন সিস্টেম।

## 🚀 দ্রুত সেটআপ (Quick Start)

### ১. গুগল শিট কানেক্ট করা:
1. আপনার Google Sheet ওপেন করে মেনু থেকে **Extensions ➔ Apps Script** এ যান।
2. `google-apps-script/Code.gs` ফাইলের সম্পূর্ণ কোড সেখানে পেস্ট করুন।
3. **Deploy ➔ New deployment ➔ Web app** (Execute as: **Me**, Who has access: **Anyone**) দিয়ে Deploy করুন।
4. ডিপ্লয় শেষে পাওয়া **Web app URL** টি কপি করুন।

### ২. ওয়েবসাইটে লিংক বসানো:
`js/config.js` ফাইলটি খুলে আপনার লিংকগুলো বসিয়ে দিন:
```javascript
window.SITE_CONFIG = {
  // আপনার Apps Script এর Web App URL
  apiEndpoint: "https://script.google.com/macros/s/YOUR_API_ID/exec",

  // আপনার গুগল শিটের সম্পূর্ণ ব্রাউজার লিংক
  sheetUrl: "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit",

  // ফেসবুক পিক্সেল আইডি (থাকলে দিন, না থাকলে ফাঁকা রাখুন)
  pixel: {
    enabled: true,
    pixelId: "123456789012345"
  }
};
```

সম্পূর্ণ বিস্তারিত ও ছবির মতো ব্যাখ্যার জন্য **[SETUP-GUIDE.md](SETUP-GUIDE.md)** ফাইলটি পড়ুন।
