# খাঁটি মধু ও প্রিমিয়াম হানি নাট ল্যান্ডিং পেজ (Honey & Honey Nut Landing Page)

একটি সম্পূর্ণ প্রফেশনাল, ফাস্ট এবং কনভার্শন-অপ্টিমাইজড ল্যান্ডিং পেজ—যেখানে কাস্টমাররা **খাঁটি মধু** এবং **প্রিমিয়াম হানি নাট** একসাথে বা আলাদাভাবে এক বা একাধিক (Multiple Products) সিলেক্ট করে অর্ডার করতে পারবেন।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **একত্রে মধু ও হানি নাট বিক্রয়:**
   - খাঁটি মধু (৫০০ গ্রাম ও ১ কেজি)
   - প্রিমিয়াম হানি নাট (৫০০ গ্রাম ও ১ কেজি)
   - মেগা কম্বো প্যাক (মধু + হানি নাট)
2. **মাল্টিপল প্রোডাক্ট চেকআউট (Multiple Product Selection):**
   - কাস্টমার একসাথে যত খুশি পণ্য সিলেক্ট করতে পারেন।
   - প্রতি আইটেমের সাথে নিজস্ব কোয়ান্টিটি কাউন্টার (+ / -)।
   - রিয়েল-টাইমে সাব-টোটাল, ডিসকাউন্ট, ডেলিভারি চার্জ ও সর্বমোট হিসাব।
3. **নন-টেকনিক্যাল ইউজারদের জন্য সহজ কনফিগারেশন:**
   - গুগল শিট স্ক্রিপ্ট (`google-apps-script/Code.gs`) এবং ফ্রন্টএন্ড কনফিগ (`js/config.js`) খুব সুন্দরভাবে সাজানো হয়েছে যাতে একজন সাধারণ মানুষও কোনো কোডিং না জেনে দাম, ডিসকাউন্ট ও শিট আইডি পরিবর্তন করতে পারেন।

## 🚀 গুগল শিট ও অর্ডার সিস্টেম সেটআপ নির্দেশিকা (Step-by-step Setup)

### ধাপ ১: গুগল শিট প্রস্তুত করা
1. [Google Sheets](https://sheets.google.com)-এ গিয়ে একটি নতুন স্প্রেডশীট তৈরি করুন (নাম দিতে পারেন: "Honey & Honey Nut Orders")।
2. উপরের মেনু থেকে **Extensions ➔ Apps Script** এ ক্লিক করুন।

### ধাপ ২: কোড পেস্ট ও কনফিগারেশন
1. Apps Script এডিটর ওপেন হলে আগের সব কোড মুছে দিন।
2. এই প্রজেক্টের `google-apps-script/Code.gs` ফাইলের সমস্ত কোড কপি করে সেখানে পেস্ট করুন।
3. ফাইলের একদম উপরে **সহজ কনফিগারেশন সেকশন** রয়েছে:
   - **পণ্যের মূল্য পরিবর্তন:** `PRODUCTS_CONFIG` সেকশনে গিয়ে যেকোনো পণ্যের নাম ও দাম পরিবর্তন করতে পারেন।
   - **ডিসকাউন্ট পরিবর্তন:** `DISCOUNT_CONFIG` সেকশনে গিয়ে ডিসকাউন্ট চালু/বন্ধ (`true`/`false`) করতে পারেন এবং ছাড়ের পরিমাণ নির্ধারণ করতে পারেন।
   - **ডেলিভারি চার্জ:** `SHIPPING_CONFIG` সেকশনে ঢাকার ভিতরে ও বাইরের চার্জ পরিবর্তন করতে পারেন।
4. কোডটি সেভ করতে ওপরের ফ্লপি ডিস্ক আইকনটিতে (💾) ক্লিক করুন।

### ধাপ ৩: ওয়েব অ্যাপ ডিপ্লয় করা (Deploy Web App)
1. উপরের ডানপাশে নীল রঙের **Deploy** বাটনে ক্লিক করে **New deployment** সিলেক্ট করুন।
2. বাঁপাশের গিয়ার (⚙️) আইকন থেকে **Web app** সিলেক্ট করুন:
   - **Description:** `Honey Nut Order API`
   - **Execute as:** `Me (আপনার ইমেইল)`
   - **Who has access:** `Anyone` (এটি অত্যন্ত গুরুত্বপূর্ণ, যাতে কাস্টমাররা অর্ডার সাবমিট করতে পারে)
3. **Deploy** বাটনে ক্লিক করুন।
4. অনুমতি (Permission) চাইলে **Authorize access** দিন, আপনার জিমেইল একাউন্ট সিলেক্ট করুন, এরপর **Advanced ➔ Go to ... (unsafe)** এ ক্লিক করে **Allow** দিন।
5. ডিপ্লয় শেষ হলে একটি **Web app URL** দেখতে পাবেন (যার শেষে `/exec` লেখা থাকে)। সেই URL টি কপি করুন।

### ধাপ ৪: ওয়েবসাইটে Web App URL বসানো
1. আপনার প্রজেক্টের `js/config.js` ফাইলটি খুলুন।
2. ৯ নম্বর লাইনে `apiEndpoint: ""` এর কোটেশনের ভেতরে আপনার কপি করা Web App URL টি পেস্ট করে সেভ করুন।
   ```javascript
   apiEndpoint: "https://script.google.com/macros/s/AKfycbx.../exec",
   ```
3. ব্যাস! এখন আপনার ওয়েবসাইট থেকে যেকেউ অর্ডার করলে সাথে সাথে গুগল শিটের `Orders` ট্যাবে অর্ডারের সম্পূর্ণ বিবরণ জমা হবে।

## 🛠️ পণ্য ও দাম পরিবর্তনের সহজ নিয়ম

কখনো পণ্যের দাম বা ডিসকাউন্ট আপডেট করতে চাইলে:
1. `js/config.js` ফাইলে দাম পরিবর্তন করুন।
2. `google-apps-script/Code.gs` ফাইলে একই দাম ও আইডি আপডেট করুন।
3. **গুরুত্বপূর্ণ:** Apps Script এ কোড পরিবর্তন করার পর অবশ্যই:
   - **Deploy ➔ Manage deployments** এ যান।
   - পেন্সিল (Edit) আইকনে ক্লিক করুন।
   - Version মেনু থেকে **New version** সিলেক্ট করে **Deploy** করুন।

## 💻 লোকাল মেশিনে চালিয়ে দেখার নিয়ম
- `index.html` ফাইলটি যেকোনো ব্রাউজারে ডাবল ক্লিক করে ওপেন করতে পারেন।
- অথবা টার্মিনালে রান করতে পারেন:
  ```bash
  python -m http.server 8000
  ```
  এরপর ব্রাউজারে `http://localhost:8000` এ যান।
