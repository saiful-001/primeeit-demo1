📑 Google Sheets Settings & One-Click Design Sync

🚀 ১-ক্লিক রিমোট শিট ডিজাইন সিঙ্ক (One-Click Sheet Design Sync)

গুগল শিটে বারবার কোড কপি-পেস্ট করার কোনো প্রয়োজন নেই! নিচের "Sync Sheet Design Now" বাটনে ক্লিক করলে আপনার গুগল শিটের সকল ট্যাব (Orders, User Activity, Pixel, Monthly Report) নিখুঁত আধুনিক ডিজাইনে অটো-সিঙ্ক হয়ে যাবে।

Google Sheets API Connection

আপনার গুগল শিট এবং Apps Script ওয়েব অ্যাপ লিংক এখানে যুক্ত করুন।

Google Apps Script থেকে Deploy ➔ New deployment ➔ Web app হিসেবে প্রাপ্ত /exec লিংক।
আপনার মূল গুগল শিটের সম্পূর্ণ লিংকটি এখানে দিন।

Modern 4-Tab Organized CRM Architecture

আপনার রিকোয়ারমেন্ট অনুযায়ী ডাটা সুনির্দিষ্ট ৪টি ট্যাবে সাজানো থাকে:

1. Orders Sheet

KPI: Total Orders, Total Revenue, Completed Orders
Note: Pixel Event & Live Sync এখান থেকে বাদ দিয়ে User Activity শিটে দেয়া হয়েছে।
Columns: Order ID, Date & Time, Customer Name, Phone, District, Address, Products, Items Qty, Subtotal, Delivery, Charge, Grand Total, Note, Status.

2. User Activity Sheet

KPI: Total Visitors, Purchases, Live Real-time Sync
Reference Design: হুবহু আপনার পাঠানো ডার্ক নেভি হেডার ও পার্পল কলাম ফরম্যাটে সাজানো।
Columns: Session ID, Last Updated, Time Spent, Selected Products, Order Completed?, Pixel Event, Customer Phone, fbclid, _fbp, _fbc, Campaign, Ad Content, Device, Traffic Source, Page URL.

3. Pixel Data Sheet

Meta Pixel Tracker: Event Name, Event ID, Page URL, Product / Value, Visitor ID, Device, Browser, UTM Source, UTM Campaign, Date & Time.

4. Monthly Report

Automated Summary: Date-wise Aggregation: Date, Total Orders, Total Contacts, Total Visitors, Total Revenue, Completed Orders, Pending Orders.
